- [x] 2.2 Príprava a kontrola .env.production na VPS:
  - Pripravený overovací skript deploy/vps/verify-vps-env.sh (kontrola chmod 600, kontrola povinných kľúčov v stave SET a zákaz nešifrovaných HTTP bez úniku tajomstiev).
- [x] 2.3 Kontrola konfigurácie Apache reverznej proxy:
  - Pripravená kanonická konfigurácia deploy/vps/apache-pandora.conf (porty 80/443 -> loopback :3005, X-Real-IP override, 600s AI timeout, WebSocket rewrite).
  - Pripravený údržbový VirtualHost deploy/vps/000-maintenance.conf a deploy/vps/maintenance.html.
- [x] 2.4 Kontrola Hetzner S3 Object Lock (WORM):

## 📌 KROK 4: Riadené nasadenie a Staging E2E Smoke Test (Release Gate)
> Cieľ: Až keď infraštruktúra aj worker stoja, nasadí sa nová verzia aplikácie v servisnom okne a otestuje sa kompletný forenzný tok na syntetickom prípade.

- [ ] 4.1 Servisné okno — Deployment aplikácie:
  - Aktivácia údržbovej stránky na Apache proxy: sudo a2ensite 000-maintenance.conf && sudo systemctl reload apache2.
  - Pull nového image digestu z GHCR: docker pull ghcr.io/.../pandora:sha-....
  - Štart kontajnera: docker-compose -f docker-compose.production.yml up -d --force-recreate app.
- [ ] 4.2 Healthcheck & Diagnostika:
  - Overiť curl -k https://127.0.0.1:3005/healthz (HTTP 200).
  - Overiť curl -k https://127.0.0.1:3005/api/health/public/ (všetkých 15 sledovaných kategórií vrátane S3 vaultu a databázy v stave ok).
- [ ] 4.3 E2E test na syntetickom prípade (Overenie celého reťazca):
  - Prihlásenie pozvaného vyšetrovateľa cez session bridge.
  - Vytvorenie syntetického testovacieho prípadu.
  - Presigned upload testovacieho súboru priamo do Hetzner S3.
  - Serverový streamovaný prepočet SHA-256 hashu a commit do auditného ledgeru (verified).
  - Spustenie AI analýzy s redakciou citlivých dát a overenie neúplných výstupov.
  - Generovanie PDF exportu spolu s nezávislým SHA-256 manifestom.
- [ ] 4.4 Návrat z údržbového módu:
  - Deaktivácia údržbovej stránky v Apache a sprístupnenie prevádzky pre pozvaných pilotných používateľov.
